# Poverty Perception Classification

This project uses a survey of 20,000+ individuals to try and model the predictive relationship between socioeconomic variables and individuals' perception of their own wealth. 
In the survey, there were about 100 questionnaires, each aiming to retrieve a response about some social or economic variates, including family status, education status, etc. The dataset provides labels as a class, ranging from 1 to 10, 1 indicating the individual does not perceive themselves to be in poverty, and 10 indicating the individual perceives themselves to be in deep poverty. 

This repository outlines the following processes:
1) Preprocessing the survey data
2) Exploring the data for potential patterns and feature selection
3) Model building using classification techniques and ensembling
4) Training and testing model
5) Evaluating model
